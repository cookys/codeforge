# CodeForge: View Pet Status

Use this skill to check your companion pet's current status.

## Instructions

Run: `codeforge pet`

This shows:
- Your pet's ASCII art and village affiliation
- Current level and XP progress bar
- Five attribute stats (ATK/HP/DEF/SUP/VER)
- Earned badges

Your pet gains XP automatically from using memory tools:
- `codeforge learn` → +5 XP
- `codeforge dream` → +10 XP
- `codeforge memory search` → +1 XP
- `codeforge ingest` → +2 XP per entry
