# CodeForge: Adopt a Pet

Use this skill to select your starter village and companion pet.

## Instructions

Run: `codeforge adopt`

This will show you the 5 starter villages. Each village corresponds to a programming language and comes with a unique companion pet. Choose wisely — your pet grows based on how you use CodeForge's memory tools.

Options:
1. **Scriptorium Vast** (Python) — Spam the Parrot
2. **Border Garrison** (TypeScript) — Blueprint the Hound
3. **The Forge-Ruins** (Rust) — Ferris the Crab
4. **Dockside Workshop** (Go) — the Gopher
5. **Strata Bazaar** (JavaScript) — Wat the Monster

Or type **R** for a random pick (+10% all stats).
