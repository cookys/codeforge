- 全部席位都過期：整池算過期，顯示舊值並加 ✖。
- band 的「最危險的池」也用同一個函式。
- 展開各席時，每個過期席位都各自標 ✖。

## A7 額度判定表補充（G8，補充 §4.1）
有 pace 時，優先序由上往下：
1. `limit_hit`（已用完）且換池資料是 null → 紅：「已用完，換池資料無來源」。
2. 預計重置前用完（P > 100%），而且 `stranded_seats` > 0 → 紅：「約 X 時後用完，N 席沒池可切」。
3. P > 100%，`stranded_seats` == 0（可以切池）→ 綠：「約 X 時後用完，席位可切池」。
4. P > 100%，換池資料是 null（r5 之前）→ 紅：「約 X 時後用完，換池資料無來源」。
5. 95% ≤ P ≤ 100% → 綠；P < 95% → 黃：「約剩 Y% 會浪費」。

- 拿掉 ↑。quota.pools 沒有趨勢欄位，pane 也不重算。
- 紅色之間的排序：`limit_hit` → 最早有限的 `projected_exhaustion_at_ms` → 過期的池（最舊的排前面）。黃色依浪費比例由多到少，然後才是綠色。band 和現況頁共用這個排序函式。

## A5' 鍵表依 host 限制修正（取代 A5 的 Space／`?`／PgUp／PgDn；11-18 03:xx，autopilot 01M7NDJF）
host 的 Button `hotkey` 只收「一個數字或一個小寫字母」，其他值會被拒絕（plugin-authoring types/claude-code.d.ts 1391–1399、11744–11750）。mod 沒有接收任意按鍵的 API。所以：
- 鍵表：`j`/`k` 移動、`z` 折疊（原本是 Space）、`h`/`l` 上一張／下一張（原本是 `[`/`]`）、`s` 送出、`a`–`e` 選擇、`n` 補充、`u` 撤回、`f` 填入、`i` 說明（原本是 `?`）。捲動用 host 原生的方向鍵，PgUp/PgDn 拿掉。`Enter` 一律交給 host，按目前焦點所在的 Button。
- **band 上的 Button 不綁數字 hotkey**：d.ts 寫明「composer 是空的時候，單一數字會按到 band 的 Button」，綁了就會吃掉操作員在空提示列打的第一個數字。1–8、9、0 只綁在 pane 內的分頁列。
- 兩個 plugin 綁同一個 hotkey 時兩個都不會觸發，所以 forge-stats 不綁 hotkey。
- 畫面上的鍵提示必須是有綁定的 hotkey（autopilot 加測試）。keys.test 依新表改寫（patch 0004）。
- **焦點列的動作用 `o`**（autopilot 01M7NDPY 選 B）：焦點列是 pane 自己記的那一列（▸），按 `o` 執行：3 艦隊是「看」（1 現況沒有焦點列，不綁 o，autopilot 01M7NE3K），4 額度是展開或收合各席，8 殘留是清掉。Enter 只按 host 焦點所在的 Button，不對焦點列動作。
- 待決卡選項上限 5 個，`a`–`e` 就夠，A5 的「舊 6 選項卡」條目和示意圖拿掉。

## A7' 換池資料缺失 = 判定未知（取代 A7 第 1、4 條；PM 01M7NJAS，11-18 04:xx，閘門 b1 第 1 輪 astra M6）
- 「已用完」或「P > 100%」而換池資料是 null：判 **unknown**，不是紅。缺資料就是未知，不能當成「確定沒池可切」（紅的定義見 01M7N41T）。
- unknown 的顏色和黃同一級，不能是綠。文字寫出缺哪份資料、由誰補，例如「判定未知：缺換池資料（capacity）」。
- band 和現況頁的排序：紅 → unknown → 黃 → 綠；沒有紅時 unknown 排第一。
- 「沒有要你處理的事」只有在 0 張待決卡且沒有任何 unknown 時才顯示；其他時候缺資料寫「資料不足，無法判定」。
