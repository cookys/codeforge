# R1 U0：forge-stats Pane 與 live pane 0／5／7 頁對照（單 01M88J46，2026-11-25）

讀的是 codeforge develop 7b19615 的 `plugins/forge-stats/hooks/`，以及 autopilot origin/develop c1cbf4c86 的 `mods/live/pages/`（haiku 讀檔，本席抽查）。這份是 U3c 的範圍依據；U4 要等 U3c 補齊、審過、合併之後才能讓 forge-stats Pane 退役。

## 探針
宿主 API 的 `ui.open` 說明寫「A pane another plugin holds is refused」，而且 `PaneOpenArgs` 沒有 plugin 或 view 欄位 → PM 裁 A（01M88NQREZ）：`/forge-stats` 改成把 `/live-pane <頁>` 填進輸入框。詳見計畫的 D4。

## live pane 缺的（依重要性）

1. **艦隊頁（forge-stats「全部帳號」↔ live 7）兩邊的內容完全不同**：forge-stats 這頁是每個帳號的配額，資料來自 `fleet-quota.json`（`fleet-view.ts:186-274`），內容有每週和 5h 兩個窗口的用量、會浪費／會不夠的警告、預估用完時間、目標 %、帳號名稱、方案、主機（含舊主機）、操作員附註和重置規則、來源說明、略過的檔案數、檔案的時間。live 的 fleet 頁（`fleet.ts:66-223`）是待決卡和執行中的工作，這些一項都沒有。
2. **用量頁（forge-stats usage ↔ live 5 spend）**：
   - 每個模型的名稱、token 數、請求數（`register.tsx:508-512`）：live 只有今天的 token 總數（`spend.ts:225-229`）。
   - 金額：每個模型的金額、總額（標成 API 等價估計）、沒有單價的筆數（`register.tsx:510-522`）。live 的 spend 頁在 `spend.ts:2` 明定「No money anywhere」，所以這是**設計上的衝突**，不是漏掉，要 PM 裁決。
   - 每個帳號的 5h／7d 窗口：live 只有自己這席的（`spend.ts:183-199`），也沒有「6 小時內沒有帳號」這句提示（`register.tsx:484-490`）。
3. **寵物頁（forge-stats pet ↔ live 0）**：forge-stats 有名稱、等級、XP 量表、ATK／HP／DEF／SUP／VER、策略、寵物說的話、村莊名稱和語言、沒有圖時改用的文字圖（`register.tsx:224-242`）。live 只畫 icon、標題、sprite 和 `pet.tiers` 的列（`pettab.ts:105-107`）；`pet.tiers` 由 forge-stats 的 `panel.ts:28` 產生，裡面有沒有上面這些欄位還沒逐項核對。

live 有、forge-stats 沒有的：資源池表、資源池 ETA、24 小時趨勢、tok/s 速度、待決卡和執行中的工作。這些照舊保留。

## 互動
- forge-stats：頁籤可點（`register.tsx:681-700`）、可捲動、`/forge-stats usage|pet|layout band`（`register.tsx:580-602`）。
- live：數字鍵切頁（5 spend、7 fleet，pet 用 `PET_KEY`）、`u`→spend、`p`→pet。
