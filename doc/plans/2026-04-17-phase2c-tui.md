# Plan — Phase 2c TUI + Local Map

## 資料流

```
     daemon tick (每 60s)              TUI (每 1s)
          │                                │
          ▼                                ▼
   pet_snapshot ← serialize_to_db    load_from_db
   combat_log   ← append per defeat    ↓
   mobs         ← scanner upserts    panels render
   loot_inventory ← aggregates           ↓
                                     diff write → stdout
```

TUI 是 SQLite 的讀者；完全不寫 derived state。符合 Two-writer rule。

## Event loop

```rust
async fn run(ctx: &Context) -> Result<()> {
    let _guard = TerminalGuard::new()?;         // enter alt-screen + raw mode
    let shutdown = Arc::new(Notify::new());

    // Spawn keyboard reader
    tokio::spawn(keyboard_task(shutdown.clone()));

    let mut ticker = interval(Duration::from_secs(1));
    loop {
        tokio::select! {
            _ = ticker.tick() => { render_frame(&ctx)?; }
            _ = shutdown.notified() => break,
        }
    }
    // _guard drop restores terminal
    Ok(())
}
```

Keyboard task 阻塞在 `crossterm::event::read`，遇 `q` / `Esc` / `Ctrl-C` 呼叫 `shutdown.notify_one()`。

## Terminal guard (panic-safe)

```rust
pub struct TerminalGuard;

impl TerminalGuard {
    pub fn new() -> Result<Self> {
        terminal::enable_raw_mode()?;
        execute!(io::stdout(),
            terminal::EnterAlternateScreen,
            cursor::Hide,
        )?;
        Ok(Self)
    }
}

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        // best-effort restore — if stdout is already closed, nothing we can do
        let _ = execute!(io::stdout(),
            cursor::Show,
            terminal::LeaveAlternateScreen,
        );
        let _ = terminal::disable_raw_mode();
    }
}
```

Drop 在 panic unwind 時也會跑 → 終端狀態不會卡在 raw mode / alt-screen。

## 測試策略

| 層次 | 目標 | 方法 |
|------|------|------|
| Unit | panel renderer 純函式 | fixed PetState / Vec<CombatLogRow> → assert_eq! on `Vec<String>` |
| Unit | local_map 分組 | 注入 fixture mobs → 驗證 RoomSummary 結構 |
| Unit | layout 算術 | 給 terminal size → 驗證每個 region 的 (x,y,w,h) |
| Unit | TerminalGuard drop | mock io::stdout，驗證 Drop 有送 escape sequence（用 `termion::event::Event` 或 pipe） |
| Integration | 完整 render 1 frame | in-memory DB fixture → call `render_to_string()` → diff against golden |
| Perf | budget 檢查 | 50 iterations of render_frame → avg < 16ms |

## Risk mitigations

1. **Render panic**：panel renderer 絕不 panic（用 saturating_sub / chars().take）。若 assert 失敗，guard 的 Drop 會先恢復終端，再 panic 傳到 main → stderr 訊息使用者看得到。
2. **Term resize**：Phase 2c 初版不支援 live resize。若視窗縮小，新的 frame 會 clear + 重畫；超出的行數直接捨棄。
3. **SQLite BUSY**：render 讀是 WAL read，不需 exclusive lock。若偶發 BUSY，frame skip（印 cached 上次 frame），不 crash。
4. **Daemon 沒跑**：TUI 單純讀 pet_snapshot；讀不到就顯示「尚未有 tick」提示，不卡住。
