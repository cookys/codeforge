## K1（keyprobe 新發現，astra M03 的根因）

80x24 按 0 後確實切到鍛造頁，但有兩個問題：
- 頁面一開就捲在底部，第一列是「上面還有 18 行」，看不到頁首。
- 這頁自己畫了一條舊分頁列「1: 現況 2: 待決 5: 派工 6: 審查 4: 花費 8: 殘留 3: 艦隊 ?」，4 寫成花費，跟共用分頁列的「4: 額 7: 花」不一致。

處置：
- 切頁時捲到頂端。
- 鍛造頁拿掉自己的分頁列，改用共用分頁列。

紅測：
- 按 0 後第一列是鍛造頁的頁首。
- 每一頁都只有一條分頁列，而且編號和共用分頁列一致。
