# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its Code of Conduct. The full text is available at the link below.

## Our pledge

We pledge to make participation in this project a welcoming and respectful experience for everyone, regardless of background or identity. We are committed to acting and interacting in ways that contribute to an open, friendly, and healthy community.

## Standards

Project conventions live in [CLAUDE.md](CLAUDE.md) and [CONTRIBUTING.md](CONTRIBUTING.md). The full standards (expected behaviors, unacceptable behaviors, scope, enforcement) are documented in the canonical Contributor Covenant 2.1 text linked below — by participating in this project you agree to follow them.

## Reporting

If you observe behavior that is inconsistent with this Code of Conduct, please report it to the project maintainers by:

1. Opening a [GitHub issue](https://github.com/cookys/codeforge/issues/new) with the `conduct` label, **or**
2. Contacting the maintainer directly via the email listed on [github.com/cookys](https://github.com/cookys) (for sensitive reports).

All reports will be reviewed promptly and confidentially. Maintainers commit to respecting the privacy of the reporter.

## Enforcement

Maintainers may apply the [Contributor Covenant 2.1 enforcement guidelines][cc-enforce] in response to reports — ranging from a private warning to a permanent ban from project spaces, depending on severity and context.
